# Customize zsh

Переносимая конфигурация zsh для macOS и Linux: плагины через Antidote, приглашение Starship, история, автодополнение, поиск через fzf и полезные CLI-алиасы.

## Поддержка и требования

| ОС | Выпуски | Пакетный менеджер |
| --- | --- | --- |
| macOS на Apple Silicon | 15 и новее | Homebrew |
| Debian | 12, 13 | `apt` |
| Ubuntu | 24.04, 26.04 | `apt` |
| Fedora | 43, 44 | `dnf` |
| Arch Linux | актуальный выпуск | `pacman` |

Заранее установите `zsh` и, на macOS, Homebrew. Установщик не устанавливает zsh и не меняет оболочку входа. Ему нужны сеть и возможность устанавливать пакеты; пакетный менеджер может запросить пароль через `sudo`.

## Установка

```sh
git clone git@github.com:kolez0/customize-zsh.git
cd customize-zsh
./install.sh
```

Установщик добавляет один помеченный блок в `${ZDOTDIR:-$HOME}/.zshrc`, сохраняя остальные строки. Он устанавливает недостающие Vim, Git, Starship (не ниже 1.22), fzf, fd, bat, eza, ripgrep, zoxide и Antidote. При замене существующих файлов создаёт резервные копии. После установки откройте новую сессию zsh или выполните `source "${ZDOTDIR:-$HOME}/.zshrc"`.

Конфигурация хранится в `${XDG_CONFIG_HOME:-$HOME/.config}/customize-zsh/zsh/`, основной prompt — в `${XDG_CONFIG_HOME:-$HOME/.config}/starship.toml`. Настройки для конкретного компьютера добавляйте в `customize-zsh/zsh/local.zsh`: повторная установка не перезаписывает этот файл.

## Использование

- `Ctrl+R` — поиск по истории; `Ctrl+F` и `Ctrl+T` — поиск и вставка пути к файлу; `Alt+C` — переход в каталог через fzf.
- `zplugin-update` — обновление плагинов через Antidote. Обычный запуск zsh не обращается к сети.
- В окне шириной меньше 120 колонок Starship использует компактный prompt без версий языков. Для значков нужен **JetBrainsMono Nerd Font Mono**; шрифт выбирается в настройках терминала.

## Обновление и удаление

Для обновления файлов проекта в каталоге репозитория выполните:

```sh
git pull --ff-only
./install.sh
```

Установщик проверяет наличие системных пакетов и устанавливает только недостающие; `apt-get update` запускается лишь когда нужны пакеты из apt. Он пропускает неизменившиеся файлы и сохраняет заменяемые в `${XDG_CONFIG_HOME:-$HOME/.config}/customize-zsh/backups/`. При ошибке после начала изменения конфигурации он откатывает изменения текущего запуска.

Для удаления конфигурации выполните из каталога репозитория:

```sh
./uninstall.sh
```

Скрипт удаляет свой блок из `.zshrc`, восстанавливает прежние управляемые файлы из резервных копий и удаляет созданные проектом файлы. Резервные копии, Antidote и установленные утилиты сохраняются.

## Vim

`config/vim/vimrc` устанавливается в `~/.vimrc` вместе с настройками zsh.
Существующий файл сохраняется в резервной копии; повторная установка обновляет
конфиг, а `uninstall.sh` восстанавливает первоначальный файл.
Установщик загружает vim-plug и устанавливает плагины через `PlugInstall --sync`.
Обычный запуск Vim не обращается к сети. Плагины и история undo при удалении
конфигурации сохраняются; созданный установщиком vim-plug удаляется.

Включены Darcula, lightline, NERDTree, fzf, ALE и остальные плагины исходного
конфига. `Ctrl+P` ищет файлы, `Ctrl+G` — текст, `Ctrl+N` открывает дерево,
`Ctrl+S` сохраняет, `Пробел /` снимает подсветку поиска.
Добавлены дополнение команд через Tab, сохранение выделения после изменения
отступа и восстановление позиции курсора.

ALE используется только для встроенных исправлений: `Пробел f` (или `:ALEFix`)
удаляет пробелы в конце строк и лишние пустые строки в конце файла.
Внешние проверки и дополнение ALE отключены; сохранение файла не запускает
автоматические исправления. Дополнительные программы для ALE не требуются.
